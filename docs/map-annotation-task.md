# Задание: разметить карту полигона

## Цель

Подготовить разметку объектов и точек осмотра, чтобы робот мог по текстовому заданию выбрать объект, подъехать к нему и осмотреть возможные места пострадавшего. Локализацию, управление и маршруты Nav2 программировать не нужно.

## Исходные данные

Используем карту **field-20260928**, уже подключённую к пульту и Nav2:

- `field.npz` — облако в массиве `points`, записанная траектория в `trajectory`, границы в `bounds`.
- `field.pgm` и `field.yaml` — соответствующая 2D-карта и её привязка.
- Видео объезда и фото полигона — для узнавания объектов.
- Регламент — для определения допустимых клеток остановки.

У владельца проекта файлы карты находятся в `.local/field-20260928-181623/`. Для передачи скопировать три файла карты вместе с видео и фото. Не размечать по исходному, не выровненному облаку `map.ply`.

Карта предварительная: местами есть размывание и следы людей. Не считать каждый кластер постоянным объектом, а отсутствие точек — свободным проездом.

## Координаты — обязательно

- Система координат: `map`, версия карты: `field-20260928`.
- Все координаты в метрах, Z направлена вверх.
- Сохранять исходные координаты данных: не центрировать, не масштабировать и не поворачивать облако. Вращать вид в программе можно.
- Начало координат не переносить в угол поля или стартовую клетку.
- Точка осмотра задаёт положение центра робота: `x`, `y` и направление `yaw`.
- `yaw` в радианах: 0 вдоль +X, π/2 вдоль +Y; положительный поворот против часовой стрелки при взгляде сверху.
- Для объектов достаточно контура в XY; высота необязательна.

При разметке изображения `field.pgm` брать масштаб и начало из `field.yaml`. Сейчас разрешение 0,05 м/пиксель, `origin` ≈ [-2,331073384; -2,329803852; 0]. Для пикселя с колонкой `u` и строкой `v`, считая с нуля от верхнего левого угла, и высоты изображения `H`:

```text
x = origin_x + (u + 0.5) * resolution
y = origin_y + (H - v - 0.5) * resolution
```

Формулы относятся к исходному изображению без обрезки и изменения размера, при текущем нулевом повороте `origin`. Отрицательные координаты нормальны.

## Что сделать

1. Сопоставить здания и другие постоянные ориентиры на карте, видео и фото.
2. Для каждого объекта указать ID, название, короткое описание внешности и контур на карте. Если контур неясен, указать приблизительный центр и отметить неопределённость.
3. Подобрать 1–3 кадра каждого объекта. Записать имя исходного видео и время кадра.
4. Вокруг каждого объекта отметить 2–4 точки осмотра в доступных проходах. Указать направление камеры и какую площадку рядом с объектом видно с этой точки. Не ставить точку вплотную к стене: учитывать габариты робота. Если габариты или обзор неизвестны, отметить необходимость проверки.
5. Отметить стартовую клетку и начальное направление робота по подтверждению команды. Начало записанной траектории не считать автоматически стартом соревнования.
6. Отдельно отметить мосты, узкие проходы и сомнительные участки. Не объявлять мост непроходимым только из-за его высоты.
7. Подвижные препятствия и возможные места пострадавшего отделить от постоянных объектов. Положение пострадавшего на попытке заранее неизвестно.

Точные маршруты между точками строить не нужно. Проходимость и обзор пока считаются предварительными; физическую проверку выполнит команда.

## Что сдать

- `annotated-map.png` — вид сверху с объектами, ID точек осмотра, стрелками направления и осями X/Y.
- `semantic-map.yaml` — координаты и описания по примеру ниже.
- `references/` — выбранные кадры объектов.
- Короткий список сомнительных мест в поле `notes` YAML.

Сначала разметить **один объект с двумя точками осмотра** и прислать картинку и YAML команде. После проверки координат и направлений разметить остальные.

## Пример YAML

Значения `null` заменить измеренными координатами. Не выдавать примерные числа за измеренные. Ненужное поле `center` или `footprint` можно убрать.

```yaml
map_id: field-20260928
frame_id: map
units: meters
yaw_units: radians

start:
  x: null
  y: null
  yaw: null
  confirmed: false

objects:
  - id: tower
    name: Круглая башня
    description: Высокое круглое здание с окнами
    center: [null, null]
    footprint: [] # Список вершин контура: [[x, y], ...]
    references:
      - image: references/tower-front.jpg
        source_video: null
        timestamp: null # Например, 00:02:15
    viewpoints:
      - id: tower_view_1
        x: null
        y: null
        yaw: null
        observes: Площадка рядом с башней
        verified_on_robot: false
    notes: []

special_areas: [] # Мосты, узкие проходы: название, контур/центр, комментарий
notes: []
```

## Критерий готовности

Каждый нужный ориентир узнаваем по описанию и кадрам, имеет привязку к карте и несколько точек осмотра. Все координаты относятся к одной неизменённой системе `map`; неопределённость явно отмечена. Использование заранее размеченных объектов в попытке команда отдельно согласует с регламентом/судьями.
